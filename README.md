# מטעמי בת מלך · מערכת ניהול הזמנות 🕯️

מערכת פשוטה לניהול הזמנות שבת — במקום קובץ הוורד.
הכול בקובץ אחד, בעברית, עובד מהטלפון או מהמחשב, בלי אינטרנט ובלי התקנה.

## איך משתמשים

פותחים את הקובץ `index.html` בדפדפן (כרום / ספארי) — וזהו.
הנתונים נשמרים אוטומטית בדפדפן של אותו מכשיר.

## מה יש בפנים

- **📋 הזמנות** — כל ההזמנות מסודרות לפי תאריך, כמו יומן. מי שהזמין לסוף החודש
  מחכה מתחת לתאריך שלו ולא מבלבל בספירה של השבוע. הזמנות שעברו מתקפלות למטה.
- **➕ הזמנה חדשה** — טופס עם כל התפריט: מסמנים כמויות בפלוס/מינוס במקום לכתוב.
  - סלטים עם שתי עמודות: **הוזמן** ו־**🎁 פינוק** (מה שאת מוסיפה ממך — כדי שתמיד
    תדעי מה אפשר להעביר או לשנות אם נתקעת בלי).
  - ראשונות עם כמות לכל דג (אפשר 1 מרוקאי + 1 חריימה) + חריפות והערות.
  - עיקריות, תוספות, קינוחים, חלות, עריכה — הכול עם כמויות.
  - אקסטרות בתשלום מהמחירון + שדה הערה (מה בפנים, מה בצד) + פריטים חופשיים.
  - המערכת מציעה מחיר לפי המחירון, ואת תמיד יכולה לכתוב מחיר אחר.
  - מתריעה אם הוזמנו סלטים או דגים מעבר למה שכלול בזוגית.
- **🍲 סיכום הכנות** — בוחרים תאריך ומקבלים בדיוק מה שצריך להכין:
  כמה מכל סלט (כולל כמה מזה פינוק), כמה דגים מכל סוג, עיקריות, תוספות,
  קינוחים, חלות, לוח משלוחים לפי שעות, כמה כסף נכנס וכמה נשאר לגבות.
  אפשר להדפיס או להעתיק את הכול לוואטסאפ.
- **📄 כרטיס הזמנה** — לכל הזמנה יש כרטיס בדיוק בפורמט של קובץ הוורד,
  עם כפתור העתקה (נוח לשלוח ללקוח לאישור).
- **💾 גיבוי** — שמירת קובץ גיבוי ושחזור ממנו (גם למעבר בין מכשירים).

- **👥 לקוחות** — ספר לקוחות שנבנה לבד מההזמנות: כמה הזמנות לכל לקוח, כמה
  הוציא בסך הכול, כפתור «הזמנה חדשה כמו הקודמת» וקישור וואטסאפ.
- **🧾 בונים** — הדפסת בון מעוצב לכל הזמנה (או לכל היום), עם לוגו וסך לתשלום.
- **🏷️ מדבקות לשקיות** — מדבקה לכל לקוח (שם, תאריך, מלון, כתובת, טלפון),
  עם בחירת מספר מדבקות לכל לקוח.

## טופס הזמנה ללקוחות

`order-form.html` — דף נפרד שאפשר לשלוח ללקוחות: הם ממלאים את ההזמנה בעצמם,
רואים מחיר משוער, ולוחצים «שליחה בוואטסאפ» — ההודעה מגיעה לוואטסאפ של העסק עם
סיכום קריא + קוד. במערכת, בטופס «הזמנה חדשה», מדביקים את ההודעה בתיבה
«📥 הלקוח שלח הזמנה מהטופס» — והטופס מתמלא לבד.

## קבצים

- `index.html` — מערכת הניהול לפתיחה במכשיר (זה הקובץ שעובדים איתו).
- `order-form.html` — טופס ההזמנה ללקוחות, לפתיחה או לשיתוף.
- `app.html`, `order.html` — אותו תוכן, גרסאות לפרסום כ־Artifact בקלוד.
